## 背景・目的

ヘルムホルツコイルは「中心付近に一様な磁場をつくる」装置として知られていますが、評価されるのはほとんどの場合、その中心部分の磁場だけです。中心から離れた場所で、空間にどのような磁場ができているのかは分かりづらいままです。

このツールは、その磁場を実際に可視化して、**どの場所にどのくらいの強さの磁場が発生しているのか**を分かりやすくすることを目的にしています。たとえば、原子セルのように、中心ではない場所に置くものの磁場環境を見積もる用途を想定しています。

そのために、グラフを取る直線の位置と、ヒートマップの断面の位置を、自由に変えられるようにしています。

## 何がわかるか

リング半径 a = 0.1 m、電流 I = 1 A の例です（磁場の強さは電流に比例し、空間的な広がりは半径に比例します）。

- 中心の磁場は約 8.99 µT。中心の値から 1% 以内に収まるのは、x 方向で中心から約 38 mm（半径の約 38%）、z 方向で約 31 mm（約 31%）まで
- z 軸から少し外れた直線（x = 3 cm, y = 2 cm）では、z = 0 の磁場は中心より 0.8% 低く、z = ±36 mm 付近に中心より 2.8% 強い「こぶ」ができる
- コイルの導線に近づくと磁場は急に強くなる（導線の近傍は発散するため、計算できない領域として扱う）

## 特徴

- 電流 [A] とリング半径 [m] を入力して計算
- **グラフ**: x / y / z のいずれかの軸方向の直線上の磁場の強さ。直線が通る位置（他の 2 座標）を指定できる
- **ヒートマップ**: xy / xz / yz のいずれかの断面の磁場の強さ。断面の位置（垂直な軸の座標）を指定できる
- コイルと、選んだ直線・断面の位置関係を 3D で表示（半径や位置を変えるとすぐ更新）
- グラフ・ヒートマップはそれぞれ PNG / PDF / SVG で保存可能

## 必要なライブラリ

動かすには、次のライブラリが必要です。`requirements.txt` にまとめてあります。

| ライブラリ | 用途 | インストール |
|---|---|---|
| [NumPy](https://numpy.org/) | 座標の格子・点列の生成、配列計算 | `pip install numpy` |
| [SciPy](https://scipy.org/) | ビオ・サバールの法則の数値積分（`scipy.integrate.quad`） | `pip install scipy` |
| [Matplotlib](https://matplotlib.org/) 3.4 以上 | グラフ・ヒートマップの作図、GUI への埋め込み、3D 表示 | `pip install matplotlib` |
| [Tkinter](https://docs.python.org/ja/3/library/tkinter.html) | GUI（Python 標準ライブラリ。pip では入れない） | 下記参照 |

Tkinter は、Windows / macOS の公式 Python には最初から入っています。Linux では別途インストールが必要です（例: `sudo apt install python3-tk`）。

上記以外は Python の標準ライブラリ（`math`, `threading`, `dataclasses`, `warnings`, `time`）のみです。

確認環境（計算と作図）: Python 3.13 / NumPy 2.5 / SciPy 1.18 / Matplotlib 3.11

## 動かし方

```bash
pip install -r requirements.txt
python GUI.py
```

## 使い方

1. 電流とリング半径を入力する
2. グラフの軸と、その軸が通る位置（固定座標）を入力する（例: z 軸なら x と y）
3. ヒートマップの投影面と、断面の位置を入力する（例: xz 面なら y）
4. 「計算実行」を押す。計算が終わったら、画面の案内に従ってグラフとヒートマップを作成する

計算には 10 秒ほどかかります（ヒートマップ 101×101 点、数値積分のため）。

### モジュールとして使う

GUI を使わず、計算と作図だけを呼び出すこともできます。

```python
import FieldResult as FR

a, I = 0.1, 1.0                                       # リング半径 [m], 電流 [A]
grid = FR.create_grid("xz", a, n=101, offset=0.03)    # y = 3 cm の xz 断面
result = FR.compute_field(grid, a, I)
fig, ax = FR.plot_heatmap(result)
fig.savefig("heatmap.png")
```

直線上のグラフは `Graph.create_line` → `Graph.compute_line` → `Graph.plot_graph` で同じように使えます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Calculation.py` | 磁場の計算（ビオ・サバールの法則を数値積分し、磁場の強さを返す） |
| `Graph.py` | 直線上の磁場のグラフの作成 |
| `FieldResult.py` | 断面の磁場のヒートマップの作成 |
| `GUI.py` | 入力・計算の流れ・表示・保存（上の 3 つを呼び出す） |

## 計算の前提

- 座標系: 2 つのリングの中点が原点、リングの軸が z 軸。リングは z = ±a/2 に置く（リング間隔 = 半径 a、ヘルムホルツ条件）
- 1 巻きの理想的な円形ループ（導線の太さは無視）、2 つのリングに同じ向きの電流を流す、静磁場
- 中心磁場は理論値 (4/5)^(3/2) μ0 I / a と一致する
- 表示は磁場の強さ（大きさ）のみ。単位は T
- ヒートマップの色は 0 〜 中心磁場。中心磁場を超える領域は最大色で飽和する

## 既知の制限

- 導線から「半径の 0.1%」以内の点は、磁場が発散して数値積分が誤った値を返すため計算せず、欠損にしている（グラフでは線が途切れ、ヒートマップでは灰色）
- 数値積分のため計算は遅い（ヒートマップの格子数は `GUI.py` の `N_GRID` で変更できる）
- 巻数・コイル間隔・コイル形状（反ヘルムホルツなど）は変更できない
